# Site Para Maria Fernanda ♡

Um site especial criado com muito amor e carinho para a minha namorada, Maria Fernanda, com tema da Kuromi.

## 🎨 Características

- **Contador de Relacionamento**: Mostra em tempo real quanto tempo vocês estão juntos desde 09/06/2024
- **Máquina do Tempo**: Galeria de fotos com seleção aleatória - 5 fotos diferentes a cada atualização
- **Linha do Tempo**: Timeline interativa com momentos especiais (bolinhas acima da linha)
- **Playlist do Spotify**: Player integrado com autoplay e notificações de músicas
- **Design Responsivo**: Funciona perfeitamente em todos os dispositivos
- **Animações Suaves**: Transições e animações fluidas em todas as funcionalidades
- **Tema Kuromi**: Cores e elementos baseados na personagem Kuromi com PNGs fofas

## 🚀 Tecnologias Utilizadas

- **Next.js 16** - Framework React
- **React 19** - Biblioteca UI
- **TypeScript** - Tipagem estática
- **Tailwind CSS v4** - Estilização
- **shadcn/ui** - Componentes UI
- **Lucide React** - Ícones
- **Poppins** - Fonte tipográfica
- **Spotify Embed** - Integração musical

## 📱 Layout Responsivo

O site se adapta perfeitamente para:
- Desktop (1920px+)
- Tablet (768px - 1919px)
- Mobile (320px - 767px)

## ⚡ Performance

- Animações otimizadas e fluidas
